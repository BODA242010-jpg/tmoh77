# طموح — نسخة المكافآت التفاعلية

هذه الحزمة جاهزة للرفع على GitHub Pages (المستودع Tomh90). ارفع الملفات الموجودة داخل المجلد إلى جذر المستودع بنفس الأسماء.

## الجديد
- الصندوق يفتح نشاطًا فعليًا، ولا يتحول إلى مكتمل إلا بعد اختيار «أنهيت التحدي».
- أسئلة كروية تفاعلية مع التصحيح، والرسم والتلوين باللمس أو الماوس مع حفظ الرسمة وتنزيلها.
- أنشطة كتابية للقراءة والبرمجة والتصوير والكتابة والعلوم والموسيقى، مع حفظ إجابات الطالب.
- سجل الهدايا يتيح إعادة فتح جميع الأنشطة؛ وسجل الهدايا القديم محفوظ.
- تحديث ذاكرة التخزين في Service Worker دون حذف بيانات الطالب.

## المساعد الذكي
لم نعدّل دوال المساعد الذكي ولا رابط AI_URL ولا Cloudflare Worker. **لا ترفع worker.js القديم إلى Cloudflare**.

## قبل الرفع
صدّر نسخة احتياطية من إعدادات طموح إن أمكن. اختبر نشاطًا واحدًا بعد رفع الملفات وتحديث المتصفح. البيانات محفوظة على الجهاز نفسه ولا تتم مزامنتها سحابيًا.

**ملاحظة:** ملف المصدر المرفق كان يحتوي AI_URL فارغًا. استُخدم عنوان Cloudflare Worker الذي تم اختباره سابقًا في المحادثة، دون تغيير دوال أو طريقة عمل الشات بوت. يجب اختباره بعد النشر.
